Why considering LLM Gateways?

- Not every prompt task or any other agentic request requires frontier level capabilities. Using a gateway can serve as a triage for delegating requests to providers and models that are capable and less costly than may otherwise be used if manually switching between models is the only other option.
- Rules and policies can be applied to the gateway to ensure that requests are rerouted to fallbacks.
